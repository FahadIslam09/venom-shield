# VenomShield

An AI-powered snake identification and clinical envenomation triage system designed to provide rapid species detection, emergency first aid protocols, and real-time hospital antivenom locator services.

---

## Overview

VenomShield is a medical emergency application built to address snakebite incidents in Bangladesh and the Indian subcontinent. The application combines online AI vision models with an extensive 97+ species knowledge base and cloud synchronization to deliver accurate snake identification and clinical envenomation risk assessment.

When an internet connection is active, VenomShield uses AI vision processing to recognize snake species from photos and synchronizes crowdsourced species data with Supabase cloud infrastructure. When connectivity is unavailable, the application provides built-in clinical diagnostic triage, emergency first aid protocols, and local search capabilities.

---

## Core Features

### 1. AI Vision Snake Scanner
* Captures or uploads snake photographs directly from mobile cameras or gallery storage.
* Analyzes morphological characteristics such as head shape, scale texture, pupil form, and body markings.
* Validates images to filter out non-snake objects like hands, food, and scenery with automated safety warnings.
* Errs strictly on the side of safety by routing uncertain or blurry images to emergency clinical evaluation.

### 2. Cloud-Synced Snake Knowledge Base
* Pre-loaded with comprehensive medical data covering 97+ snake species.
* When AI identifies a snake, detailed first aid, symptoms, venom type, and clinical timelines load instantly.
* Newly discovered or uncatalogued snakes generated by AI automatically synchronize to Supabase cloud database.
* Synchronized species become immediately searchable across other devices upon app launch.

### 3. Symptoms and List Clinical Diagnostic Triage
* Designed for situations where a snake photo cannot be taken safely.
* Evaluates 18 World Health Organization (WHO) and National Guideline diagnostic parameters across four distinct clinical sections:
  1. Snake Physical Features and Encounter Conditions
  2. Bite Wound Characteristics and Local Reactions
  3. Critical Neurotoxic Signs such as Ptosis, Respiratory Distress, and Flaccid Paralysis
  4. Systemic, Hemotoxic, and Shock Indicators
* Applies zero false-negative safety scoring where any critical life-threatening symptom immediately triggers an emergency alert.
* Prevents accidental submissions by keeping the evaluation button disabled until at least one symptom or characteristic is selected.

### 4. Live Hospital Radar and Antivenom Locator
* Uses device GPS and mathematical Haversine calculations to measure exact distances to nearby hospitals.
* Displays stock indicators for antivenom availability and intensive care facilities.
* Supports division and district-level filtering across all administrative regions of Bangladesh.
* Provides one-tap direct calling for emergency helplines and hospitals, plus turn-by-turn navigation links.

### 5. Dual-Platform Assessment History
* Records previous scan results and symptom assessments for clinical review.
* Uses native SQLite database on Android and iOS devices, and LocalStorage on web browsers.
* Features interactive history cards:
  * Tapping a snake scan card opens full species medical profiles.
  * Tapping a symptom assessment card displays evaluated clinical signs, calculated risk percentages, and emergency steps.

### 6. Universal Bilingual Localization
* Supports instant language toggling between English and Bangla throughout all screens.
* Retains user language preferences persistently across app sessions.

## System Architecture and Technology Stack

| Layer | Technology | Function |
| :--- | :--- | :--- |
| **Frontend Framework** | Flutter 3.x with Dart 3.x | Cross-platform mobile and web application interface |
| **State Management** | Flutter Riverpod (v2.6.1) | Immutable state handling and business logic separation |
| **Routing** | GoRouter (v14.8.1) | Declarative navigation and deep-linking |
| **AI Vision Processing** | Google Gemini Vision / OpenRouter API | Visual classification and pattern recognition |
| **Cloud Synchronization** | Supabase REST Backend | Live cloud synchronization of community-discovered species |
| **Local Database** | SQLite FFI and Web LocalStorage | Persistent history and offline cached species storage |
| **Mapping and Geolocation** | Flutter Map, LatLong2, Geolocator | Distance calculations and interactive hospital maps |
| **Connectivity Observer** | Connectivity Plus | Real-time network detection and online mode indication |

## Application Workflow

```
User Action:
  │
  ├──► Take or Upload Snake Photo
  │      └──► AI Vision Model Analysis (Online)
  │             ├──► If Not Snake: Safety Alert Displayed
  │             ├──► If Unclear: Routed to Symptom Evaluation
  │             └──► If Identified:
  │                    ├──► Species Profile Loaded
  │                    └──► Uploaded to Supabase Cloud Database
  │
  └──► Select Symptoms and List Checklist (Online or Offline)
         └──► 18 Clinical Factors Evaluated
                ├──► Zero False-Negative Clinical Scoring
                ├──► Emergency Risk Assessment Displayed
                └──► Direct Routing to Hospital Radar & 999 Helpline
```

## Getting Started

### Prerequisites
* Flutter SDK (Version 3.22.0 or higher)
* Android Studio / VS Code with Flutter extensions
* Git installed

### Installation Steps

1. Clone the repository:
```bash
git clone https://github.com/FahadIslam09/venom-shield.git
cd venom-shield
```

2. Install dependencies:
```bash
flutter pub get
```

3. Run the application in Chrome browser:
```bash
flutter run -d chrome
```

4. Run all automated clinical and triage tests:
```bash
flutter test
```

5. Build Android Release APK:
```bash
flutter build apk --release
```
